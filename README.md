# Airline-Loyalty-Program-Churn-and-Analytics-

Trained a Classification Decision Tree model to predict whether a customer will churn from an airline's loyalty program.

Explored data using SQL and Python. 

The 4 most important features are: 
- Tenure (months being a loyalty member)
- Total flights (total number of flights in customer's history)
- Enrolment Type (Either standard or via the February 2018 promotion)
- Province (Province of residence)

These inference why a customer churns and what we can do to prevent it: 

1. Optimize for the program to retain usage
  - Have good loyalty offers and rewards for flying
2. Find ways to make them want to fly with the airline more
